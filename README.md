# Automated Event Certificate Generation System

A Python-based automation system that generates personalized certificates from a predefined template by extracting participant data directly from Google Forms responses.

The system eliminates manual certificate creation by dynamically rendering names and details onto certificate templates using image processing, enabling fast, error-free bulk certificate generation.

## Features
- Automatic extraction of participant data from Google Forms
- Dynamic name rendering on certificate templates
- Bulk certificate generation using image processing
- High accuracy and time-efficient automation

## Tech Stack
Python, Pillow, Google Forms, CSV Processing

## Use Cases
- Academic events and workshops
- Hackathons and competitions
- Certification programs

## How It Works
1. Collect participant responses via Google Forms  
2. Export responses as CSV  
3. Process entries using Python  
4. Generate personalized certificates automatically  

## Output
Generates ready-to-distribute certificates in bulk format.
